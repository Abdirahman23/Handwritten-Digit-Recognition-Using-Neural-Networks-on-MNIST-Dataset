# Handwritten Digit Recognition Using Neural Networks on MNIST Dataset

This project implements a handwritten digit recognition system using neural networks, trained on the MNIST dataset. The model classifies 28x28 grayscale images of handwritten digits (0-9) using a simple neural network architecture built with TensorFlow and Keras.

## Overview

The goal of this project is to build and evaluate a neural network model that can accurately classify images of handwritten digits. The dataset used is the **MNIST dataset**, a standard dataset in the field of machine learning and computer vision, containing 60,000 training images and 10,000 testing images of handwritten digits.

### Key Features:
- **Neural Network Model**: The model uses a simple architecture with dense layers, trained to classify digits.
- **Evaluation**: The performance of the model is evaluated using metrics such as accuracy, precision, and recall.
- **TensorFlow & Keras**: The model is built using TensorFlow and Keras, two widely used deep learning frameworks.
- **MNIST Dataset**: The dataset consists of grayscale images of handwritten digits, each 28x28 pixels in size.
